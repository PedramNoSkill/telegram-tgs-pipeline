# tgspipe

پایپ‌لاین کامل و سخت‌گیر برای ساخت ایموجی و استیکر متحرک تلگرام (`.tgs`): ریگ کاراکتر، ساخت، ولیدیشن با گیت‌های واقعی، بهینه‌سازی حجم، رندر پیش‌نمایش و QA تصویری — همه با یک CLI.

بیشتر ابزارهای `.tgs` فقط فایل تولید می‌کنن؛ این پروژه طوری طراحی شده که فایل بد اصلا به دستت نرسه: هر مرحله یه گیت داره و هر گیت اسم و دلیل مشخص داره.

![ci](https://github.com/PedramNoSkill/telegram-tgs-pipeline/actions/workflows/ci.yml/badge.svg)

## چرا این پروژه؟

- **ولیدیتور سخت‌گیر:** بوم 512×512، حداکثر 60 فریم‌برثانیه، حداکثر ۳ ثانیه، حداکثر 64KB، و رد کردن همه‌ی فیچرهای Lottie که تلگرام رندر نمی‌کنه (ماسک، افکت، اکسپرشن، لایه‌ی عکس/متن/سالید، ستاره، ریپیتر، مرج‌پث، گرادیان استروک و...). مشخصات کامل در `docs/telegram-limits.md`.
- **لوپ واقعاً بسته:** برای هر پراپرتی متحرک چک می‌شه که مقدار فریم آخر با فریم اول برابر باشه — و توی QA تصویری هم فریم اول و آخر با هم مقایسه می‌شن.
- **ریگ کاراکتر، نه شکل‌های پراکنده:** هر عضو بدن یه سیلوئت بزیه، یه پیوت (نقطه‌ی چرخش) و یه والد داره. بازو دور شونه می‌چرخه، نه دور مرکزش. آدیت ریگ قبل از بیلد، پیوت اشتباه و والد گمشده رو می‌گیره. جزئیات در `docs/rigging.md`.
- **بودجه‌ی حجم، نه غافلگیری:** بهینه‌ساز با گرد کردن اعشار، حذف نودهای نامرئی و فشرده‌سازی دوباره، حجم رو پایین میاره و گزارش می‌ده چقدر کم شد — بدون دست زدن به فریم‌ریت و بوم.
- **QA تصویری بدون تلگرام:** رندرر سبک با Pillow فریم‌ها رو در سایز واقعی نمایش ایموجی (100×100) رندر می‌کنه؛ گیت‌های QA درز لوپ، فریم یخ‌زده و پرش غیرعادی بین فریم‌ها رو می‌گیرن. جزئیات در `docs/qa-gates.md`.

## نصب

```bash
pip install -e ".[render]"
```

هسته‌ی پروژه هیچ وابستگی‌ای نداره (فقط کتابخانه‌ی استاندارد پایتون)؛ فقط رندر پیش‌نمایش به Pillow نیاز داره.

## استفاده

ساخت مثال آماده (کاراکتر Bobble با بازوی در حال دست‌تکون دادن):

```bash
python examples/build_bobble_blob.py
```

اجرای همه‌ی گیت‌ها روی خروجی:

```bash
tgspipe validate examples/bobble_blob.tgs
tgspipe optimize examples/bobble_blob.tgs -o examples/bobble_blob.min.tgs
tgspipe render   examples/bobble_blob.tgs --out preview.png
tgspipe qa       examples/bobble_blob.tgs
```

خروجی ولیدیتور برای یه فایل سالم:

```text
PASS: examples/bobble_blob.tgs (… bytes, 180 frames @ 60 fps)
```

## ساختار پروژه

```text
src/tgspipe/
  lottieio.py   خواندن/نوشتن .tgs و پیمایش سند Lottie
  validate.py   گیت‌های سخت مشخصات تلگرام
  build.py      ریگ کاراکتر، ایزینگ‌ها و کامپایلر Lottie
  optimize.py   رژیم حجم امن و قابل گزارش
  render.py     رندرر پیش‌نمایش فریم‌ها با Pillow
  qa.py         گیت‌های تصویری: درز لوپ و حرکت فریم‌ها
  cli.py        رابط خط فرمان tgspipe
examples/       یه کاراکتر کامل و قابل بیلد
tests/          تست‌های واحد برای همه‌ی گیت‌ها
docs/           مشخصات تلگرام، راهنمای ریگ و راهنمای QA
```
